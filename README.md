# Estudos-Java

Repositório dedicado aos meus estudos da linguagem Java, com exercícios, projetos práticos e anotações sobre os conceitos aprendidos ao longo do caminho.

## 🎯 Objetivo

Documentar minha jornada de aprendizado em Java, desde os fundamentos até tópicos mais avançados, servindo como material de consulta e prática contínua.

## 📚 Conteúdo

- Fundamentos da linguagem (variáveis, tipos de dados, operadores)
- Estruturas de controle (condicionais e loops)
- Orientação a Objetos (classes, herança, polimorfismo, interfaces)
- Coleções (List, Set, Map)
- Tratamento de exceções
- Manipulação de arquivos
- Programação funcional (streams, lambdas)
- Projetos práticos de fixação

## 🗂️ Estrutura do repositório

```
Estudos/

```

## 🛠️ Tecnologias

- **Java** (versão utilizada: JDK 17+)
- **IntelliJ IDEA** como IDE principal

## 🚀 Como executar os códigos

1. Clone o repositório:
   ```
   git clone https://github.com/seu-usuario/Estudos.git
   ```
2. Abra o projeto na sua IDE de preferência (IntelliJ, Eclipse, VS Code).
3. Compile e execute o arquivo `.java` desejado:
   ```
   javac NomeDoArquivo.java
   java NomeDoArquivo
   ```
